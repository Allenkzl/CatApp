# 阳台猫观察室

Open Datalogger 阳台猫观测与漫画工作台的第一版本地原型。先使用模拟数据体验业务流程，后续再接入实际采集、分析和生成服务。

## 启动

需要 Node.js 18 或更新版本，无需安装依赖。

```bash
npm run dev
```

在浏览器打开 http://localhost:4173 。默认只监听本机回环地址。可以使用 `PORT=4180 npm run dev` 更换端口。

## 建议体验顺序

1. 工作台：认识橘子和芝麻，查看当天事件和下一步入口。
2. 观测记录：按猫咪、日期、状态或文本筛选记录，也可以导入图片/视频。
3. 事件复核：回看参考素材，纠正身份、行为、区域、时间和时长，确认事件。
4. 习惯与画像：查看已确认片段统计；长期画像显示积累条件。
5. 漫画工作室：编排四格或六格模拟漫画，编辑对白、描述和关联事件，替换插画。
6. 勾选事实审核，保存到作品库，导出附带事实卡的 SVG 漫画。
7. 设置：修改空间和观察问题，导出 JSON，或恢复演示数据。

初始演示日期是 **2026-10-19**，包含两只猫、8 条事件，其中 5 条已确认、3 条待复核。四格可以直接编排；六格需要至少 6 条已确认且身份明确的事件。

## 当前实现与边界

- 模拟事件和数字并非真实采集；角色照片仅为参考。
- 漫画使用本地 SVG 插画和预设文本编排，未调用 AI。单格重生成是切换模拟场景。
- 事件复核驱动工作台数字、事件摘要、区域片段时长占比和漫画候选。
- 首页小时活动图、阳台地图和轨迹是固定示意，已标注，不随事件更新。
- 片段时长求和可能有重叠，不代表有效观察覆盖时长或全天活动比例。
- 不接入摄像头、坐标识别、真实行为分析、长期画像计算或外部发布。
- SVG 导出包含漫画与事实卡；暂不导出 PNG/JPG。JSON 包含记录和作品，不包含素材文件，也暂不支持 JSON 导入。
- 身份、事实有变更时，草稿与相关作品会取消审核，需更新关联事件并再次审核。
- 更换创作日期会提示先保存当前草稿，避免不同日期的事件混入每日漫画。

## 数据保存

事件、猫档案、草稿、设置与作品保存于 localStorage，上传素材保存于 IndexedDB。浏览器清理网站数据后不可恢复；不同主机名和端口有独立存储（例如 localhost 与 127.0.0.1）。统一使用 localhost:4173 体验。

支持 JPG、PNG、WebP、MP4、WebM，单份 30 MB 以内。导入会新增一条需要人工完善的待复核事件，默认值不代表识别结果。视频播放完整源文件，暂不自动截取片段。

## 项目结构

```text
index.html           页面入口
src/app.js           页面渲染、业务交互、存储、作品导出
src/data.js          初始模拟数据、行为与区域定义
src/art.js           图标、图表、漫画插画和转义工具
src/style.css        桌面与移动布局
public/              本地猫咪参考照片与图标
scripts/serve.mjs    本地静态服务器
scripts/verify.mjs   独立浏览器流程验证
docs/superpowers/    已确认的原型设计说明
docs/sessions/       按用户指令存档的会话记录
```

## 检查

```bash
npm run check
```

浏览器验证依赖 Playwright 与可用 Chrome，不是网站运行依赖。可指定现有安装的模块与浏览器，先启动本地服务再运行：

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
CHROME_PATH='/absolute/path/to/Chrome' \
node scripts/verify.mjs
```

测试使用独立浏览器会话，不修改用户正在使用的网站数据。检查筛选、复核、未知身份排除、分镜编辑、审核导出、图片导入和持久化、作品保存、事实变化后失效、日期切换及桌面/手机布局。截图和下载文件位于忽略的 `artifacts/`。
