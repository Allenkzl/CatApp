# 当前绘图规则（2026-10-29）

每日任务只自动生成英文故事。Seedream 已改为每篇故事内手动确认后付费绘图；本文后面的自动绘图说明属于历史版本。新站默认每天，已有频率选择保留。详见 [手动绘图](MANUAL_DRAWING.md)。部署核对 release=story-manual-drawing-v1。

# 每日猫咪总结

当前版本支持小时验证及正式每日总结，完整处理与部署说明见 [小时验证说明](HOURLY_VALIDATION.md)。

## 正式模式

在空间设置将“生成频率”改为“每天一篇（正式）”并保存。默认次日北京时间00:10处理完整前一天，每个摄像头/日期一篇英文故事与漫画；入队后模型处理还需要时间，不保证00:10图片已经完成。单摄像头不等于单只猫，当前尚无个体识别。

每天归档全部原图，分批分析每张照片，保存可复用观察证据，按层级汇总后编写一个有来源依据的故事，再选分镜对应照片绘图。默认目标8格，可选6–8格；照片不足时缩短，没有照片不生成。只覆盖可见观察，空白时段未知，漫画对白为创作。

首次启用总结的日期记录为dailyStartDate，不自动批量回填此前日期。重启会补建启用日起尚未建立的到期任务。固定日期/摄像头ID避免重复生成。迟到照片继续归档到作品全部来源相册，但不会悄悄加入冻结故事或自动重复付费绘图。

## 小时验证模式

本轮新站/升级缺频率的站点默认每60分钟测试一篇，起点为首次启用时间，页面显示收集窗口和下一次时间。已经选择过的daily设置保持不变。切到每天后，未完成的小时任务不再执行，已完成测试可以在折叠历史里回看，不混入每日主列表。

## 自动生成开关

网站持久化settings.autoGenerateEnabled控制，默认开启，覆盖旧CAT_AUTO_GENERATE=false，无需运维改变量或重启。已有false保留。POST /api/settings可以只保存JSON布尔开关，也可一起保存dailyTime、panelCount、summaryFrequency。

关闭时当前已发出的请求允许返回并保存，后续步骤暂停；重新开启复用成功结果。429/5xx按步骤有限重试，超时/重启中断需手动确认重试，避免重复扣费。

## 照片与预览

作品包含时段全部来源相册，24张一页，可以查看全部原图；显示逐批看图数量、汇总、故事和绘图阶段。

“预览所选日期素材”是免费只读的时间/候选素材预览，不调用AI、不提前画正式漫画。其候选图片数不代表正式生成只分析这些图片；正式任务会分批读完全部冻结来源。
