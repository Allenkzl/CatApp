# 小时测试与全天全量总结

## 验证版如何使用

本版首次升级（没有保存过频率）/新数据目录默认选择“每小时一篇（测试）”。切入小时模式时记录服务器时间作为起点，每60分钟关闭一个收集窗口，建立一篇任务；不是每三张，也不是每到整点重新分组。空窗口不生成空漫画。网页关闭不影响后台；服务器必须持续运行。

空间设置可以切换“每小时一篇（测试）”与“每天一篇（正式）”，自动生成开关仍由网站持久化控制，默认开启。已经明确保存的频率/暂停状态在重启时保留。更改篇幅不会重置小时起点；从每天切回每小时会建立新的起点。页面显示北京时间收集范围及下次入队时间。

每天模式仍在次日北京时间00:10（可配置）汇总完整前一天。当前频率之外的未完成任务不自动执行，避免切换模式产生额外批量费用；测试结果保留，但作品库默认展示当前模式，避免小时测试混入正式每天一篇。当前按摄像头分组，不声称同一摄像头里的猫已完成个体识别。

## 全量处理，而非18张抽样

1. 到时冻结该摄像头/时段所有已上传照片，固定作品ID，保存全部来源ID。
2. 每批最多6张逐张看图，要求每张都返回观察、活动及不确定性；缺失或未知ID会判失败，不伪装成全量完成。
3. 分析结果按照片ID、内容哈希、模型和分析版本持久化缓存。小时切到每天可以复用同一照片的证据，失败/重启后不必重读已经成功的照片。
4. 照片多时按12条证据分组，逐层压缩观察摘要，仍保留来源关系；将全部证据汇总成一个英文故事，目标6–8格，素材少时缩短。
5. Seedream只接收分镜引用的照片用于画图，但故事依据已覆盖全部被冻结的照片。格子不是照片一一对应。
6. 相册按24张分页，可以查看全部来源原图。迟到照片也收进对应相册，并标记“未加入已冻结故事”，不自动再付费重画。

照片里的文字/指令均视为场景数据，不作为命令。未拍到的时间、个体身份和连续行为均保持未知；漫画对白和情节属于创作。

## 进度、暂停与恢复

工作状态：逐批看图→汇总观察→英文故事→绘图→完成。显示已分析张数/冻结来源总数。每步完成后写检查点，单并发处理。暂停时已经发出的请求允许完成保存，之后的阶段停止；重新开启继续，不重复已完成阶段。

429/5xx按步骤最多3次重试，已完成的图片证据和摘要不会丢失。超时/服务中断/格式错误需手动重试，避免盲目重复付费。绘图继续保留返回PNG缓存和未人工审核标记。

## 真实供应商验证

使用云端最近6张真实照片在独立本地目录执行：6/6看图成功→一个6格英文分镜→Seedream返回PNG。未修改云端原任务。遇到并处理了：

- 英文输出的排版标点需要兼容ASCII协议；常见弯引号/长破折号/重音字符在校验前规范化，中文/非法来源仍拒绝。
- Seedream Flash拒绝1920×2560，实际API提示像素面积上限4624220；改为1728×2304（3981312像素）后成功。旧批次横图仍保留2560×1440。
- 生成图的格数/编号存在模型偏差（6格分镜的样例实际多出一个画格），仍是未审核AI输出，不能用接口成功代替视觉质量验收；新提示进一步明确两列网格及编号唯一，待用户现场验证，不自动反复付费重画。

私有验证输出保存在忽略的`.data/hourly-provider-check-*`，查看副本`artifacts/hourly-real-provider-check.png`亦忽略，不上传凭据或原照片到源码。

## 发布与验收

`/healthz`和`/api/capture`带`release: hourly-comic-v1`，网页页脚显示“小时全量测试版”。只有看到该标记、`settings.summaryFrequency=hourly`、`automation.workerEnabled=true`和有效`nextRunAt`，才算云端开始本轮测试。计时从服务器启用新窗口算起，不从GitHub推送算起。00:10或小时截止为入队时间，模型处理还需要时间。

已确认GitHub Webhook交付给Jenkins的catapp任务，过滤`^refs/heads/main$`且响应triggered=true；没有GitHub Actions流水线。Jenkins管理API403、浏览器跳转登录，现有权限只能触发构建，不能直接读取/修改构建发布配置。此前main推送成功而站点仍旧版，不能承诺等一小时便自动上线；最终以公开站标记验收。

本轮用户明确授权实现并上线，完成测试后合并推送主线。若历史Jenkins检出仍固定保留的`feature/device-upload-deployment`，可在确认祖先关系后以普通快进同步相同发布版本作为兼容，禁止强推/覆盖分叉的远端工作。默认分支仍为main。

## 验证命令

- `npm run check`
- `npm test`（含完整批量看图、层级汇总、断点复用、暂停恢复、逐步限流重试、时段边界、迟到相册）
- `npm run verify:hourly`（35张全来源分页、小时/天切换、下次时间、手机英文）
- `npm run verify:daily` 与 `npm run verify:server`

本机无Docker Engine，不宣称已本地构建/验收容器。
