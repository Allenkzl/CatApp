# 持续收图与自动英文故事：已确认设计

用户确认新建 feature/continuous-auto-comic，保留 SSH → 电脑 → 网站；每篇照片数默认3，在空间设置可调整；自动故事先使用 DeepSeek，绘图接口稍后配置。保留中英文网站与既有英文手绘回填能力。

Node 服务监督独立 Python SSH 采集子进程，持续抓拍不受漫画张数限制。原项目与 GPIO 流程保持独立。电脑和服务运行时自动处理，无需保持网页打开。摄像头登录失败不无限尝试，状态与目录同步区分。

CaptureStore 原子保存照片、作品、空间设置、当前未满组目标。以摄像头+北京时间日期分组，修改数量不影响当前未满组。单进程串行任务队列，照片导入与故事调用解耦。照片只读、重复导入去重。每组生成1–6格可读英文故事，观察证据与虚构对白分开。

密钥和SSH密码只存在本机忽略的数据目录，0600，不返回浏览器或写入Git。页面密码输入空白，后端使用固定官方DeepSeek端点。修改API有本机Host与同源校验。
