# 每日自动故事、按需付费绘图

用户2026-10-29明确要求执行：每天只自动总结一篇英文故事，绘图按钮放在每篇故事中，点击才启动 Seedream。沿用每天北京时间次日00:10、按摄像头/日期唯一、全天来源分批看图和缓存，保留小时测试模式及原始相册。

## 状态与费用边界

- 自动管线：照片 → DeepSeek 分批读图/汇总/英文故事 → `story_ready`，正常结束。此阶段仍有 DeepSeek API 费用。
- 绘图按钮 → 展示付费确认 → `POST /api/capture/works/:id/drawing` → `image_queued` → `drawing` → `completed` 或 `image_failed`。
- 后端只消费明确的 `drawingRequested` 队列。已经配置 Seedream、自动任务开启、重启、切换频率都不会让未确认的故事绘图。
- 网站自动开关只控制故事；手动确认的绘图不受此开关影响，排队确认会持久化。执行中重启变成失败，禁止盲目重发。
- 确认时生成请求 ID，保存入库，重复点击及相同请求重发不重复付费。已有漫画返回现有状态；上次失败必须再次确认可能已经计费。
- Seedream 等待上限从180秒改为600秒。超时不能证明服务商未计费；保留故事、照片、证据缓存及已返回绘图缓存，不自动重试。

## 兼容与界面

旧 `awaiting_image_provider` 故事升级到 `story_ready`；绘图失败仍可直接读故事和查看全部来源，保留失败提示和手动重试按钮。已完成漫画保持可看、可下载。小时历史保留故事以及成品。

作品卡和详情提供付费绘图按钮、排队/绘图状态；设置和首页明确“自动故事，手动绘图”，中英文均可用，故事和漫画内容保持全英文。没有绘图配置时说明先配置，按钮禁用。

## 验证与交付

隔离测试覆盖无点击零绘图、并发防重、失败后的明确确认、持久化/重启、暂停自动故事时仍可手动绘图、600秒参数、付费缓存恢复与保存回滚。浏览器覆盖故事可读、取消不请求、费用提示、排队禁重、中英及手机端。测试不调用真实付费模型。

本分支先提交待用户确认合并；部署后以 `/healthz` 的 `release=story-manual-drawing-v1` 判断版本，不能把本地完成等同于云端上线。
