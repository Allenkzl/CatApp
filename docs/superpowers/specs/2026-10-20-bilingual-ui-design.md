# 全站中英文切换

用户已确认右上角「中文 | English」切换方案，并授权新建 feature/bilingual-ui 分支。

- 默认中文，选择保存在独立的 localStorage 键中；刷新和页面导航保持语言。
- 使用共享本地词典，覆盖导航、各页面、默认演示内容、弹窗、状态提示、无障碍标签、网页标题和系统生成漫画文案。
- 模板静态文案在渲染时翻译，用户输入和采集文件名、目录、批次等原始数据保留原文；切换不改写业务数据。
- 中英文按钮均可键盘操作，标明当前选中语言，小屏幕保持可见。
- SVG 接口接受 lang 参数，默认中文；预览和下载使用当前语言，不修改历史记录与原图。
- 验证两种语言的六个页面、默认/自定义文本、弹窗、刷新持久化、目录同步和 SVG 下载，检查桌面与移动端溢出。

实现顺序：共享词典和模板翻译函数 → 页面/交互接入 → SVG 语言参数 → 隔离浏览器验证 → 项目里程碑与提交。
