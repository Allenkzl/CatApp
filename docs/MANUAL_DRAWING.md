# 每日故事与手动绘图

新版每天北京时间次日00:10，按摄像头对前一天已上传照片分批读图，生成一篇英文故事。故事完成即正常入库，不自动调用 Seedream。

1. 打开作品库，选择故事，直接阅读英文摘要与分镜，查看全部来源相册。
2. 需要漫画时点击「生成漫画（付费）」，核对费用提示，再确认。
3. 状态显示排队、绘图中，完成后自动显示漫画并可下载PNG。排队和执行时不能重复发起。
4. 失败时保留完整故事。若要重试，先查火山方舟请求/账单，再点击「重新绘图（付费）」确认。超时或失败不代表未计费。

「空间设置 → 自动整理每日故事」只控制 DeepSeek 读图和编写故事，仍会产生 DeepSeek API 费用。Seedream 无论是否已配置，均需逐篇手动确认；关闭此开关不取消你已经确认的绘图。没有来源照片的日期不会生成空故事。仍可选择小时测试模式。

## 兼容与超时

- 所有原始照片、分析缓存、英文故事和已完成漫画继续保留；旧等待绘图故事直接成为可读故事，失败图不会自动重试。
- Seedream 等待上限600秒。服务重启中的绘图标为失败，需要人工确认后重试；已确认但尚未发送的队列会恢复。
- 已返回的付费图片先写本地持久化缓存，发布失败后的手动恢复优先用同一缓存，不重复调用绘图接口。
- 不将历史照片、密钥或生产数据放入代码仓库；正常镜像更新沿用服务器原持久化目录。

## 发布核对

合并并部署本分支后，检查 `/healthz` 返回 `release: story-manual-drawing-v1`。作品详情能看到付费按钮，`/api/capture` 的 `automation.drawingMode` 为 `manual`。发布前旧程序仍遵循旧策略；推送不等于线上已升级。
